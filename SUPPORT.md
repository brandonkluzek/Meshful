# Support

Meshful is maintained as a public working project. Support is best-effort and
does not include guaranteed response times, account recovery, or individualized
course tutoring.

## Where to ask

- Use a **bug report** for reproducible product or build failures.
- Use a **Deck Library correction** for factual, wording, provenance, or
  prerequisite issues in public course content.
- Use a **feature request** for a focused learner or contributor outcome.
- Use a [private security advisory](https://github.com/brandonkluzek/Meshful/security/advisories/new)
  for vulnerabilities, exposed credentials, learner-data risks, or account
  boundary problems.

Before posting publicly, remove credentials, account identifiers, learner data,
private course material, and sensitive logs. Questions about the live service
should identify whether the behavior occurred signed in or signed out, but
should never include the account identity.

## Scope

The issue tracker covers the public repository and the behavior of
[meshful.ai](https://meshful.ai). It is not a channel for medical, legal, or
other professional advice, and Deck Library content should not be treated as a
substitute for authoritative course materials.
