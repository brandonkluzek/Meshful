# Security policy

## Supported version

Security fixes target the latest commit on `main`. No earlier release line is
currently maintained.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, learner data, or
account identifiers in a public issue. Use GitHub's private security advisory
flow at <https://github.com/brandonkluzek/Meshful/security/advisories/new>.

Include the affected commit, reproduction steps, impact, and any suggested
mitigation. Avoid accessing data that does not belong to you. The maintainer
will acknowledge the report, investigate it, and coordinate disclosure after a
fix or risk decision is available.

General product bugs that do not expose sensitive information may use the
[public issue tracker](https://github.com/brandonkluzek/Meshful/issues/new/choose).
