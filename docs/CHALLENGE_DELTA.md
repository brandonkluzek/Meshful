# Pre-existing work and WebMCP Challenge additions

## Pre-challenge baseline

Construction baseline: `62b65cc841d01f3f5144bc6aac0cbb6887f530d9`,
dated before the August 25, 2026 submission period.

The broader project already contained a local Python trainer, structured deck
and grading concepts, SQLite/FSRS study mechanics, CLI operations, authored
evaluation fixtures, and experimental adapters. Those surfaces are not in this
competition repository and should not be presented as challenge additions.

The baseline did not contain the current browser `web/` app or WebMCP tool
implementation.

## Challenge-period additions

- the Study, My Decks, Library, and Graph browser workspace;
- thirteen page-owned WebMCP tools for reads, deck authoring, and study;
- atomic `submit_grade`, retry-safe receipts, and one visible reveal;
- FSRS scheduling, prerequisite gating, deck validation, and card authoring;
- responsive UI, local KaTeX, activity/streak projections, and continuous study;
- Backend v1 plus the fragmented D1 v2 successor and both migrations;
- Accounts identity, lease, browser-outbox, and explicit local-copy boundaries;
- server-selected guest/account entries and fail-closed Website endpoint;
- a Sites wrapper and provider-free release-verification path.

## Claim boundary

Local checks establish selected mechanics and package reproducibility. They do
not establish generalized model quality, expert-gold grading accuracy, learning
outcomes, hosted account acceptance, public content rights, or submission.
