# Content and asset rights boundary

## Included owner-controlled material

- `web/data/catalog.js`: three freshly authored public examples totaling 18
  cards, with card-level public reference URLs.
- `library/**`: the exact approved sanitized academic Deck Library release,
  currently containing 72 courses and bound by `library/MANIFEST.json`.
- `web/data/library/**` and `web/data/library-releases.json`: the public-only,
  deterministic browser projection and release index for that Deck Library release.
- `site/public/og.png` and `site/public/favicon.svg`: provenance-recorded
  Meshful brand assets.
- project-authored documentation.

The original deck metadata and card text in `web/data/catalog.js` are dedicated
under CC0 1.0 Universal, without an attribution requirement. Owner-controlled
documentation and brand assets remain licensed under CC BY 4.0. Software and
software-oriented test fixtures remain under Apache-2.0. See
`LICENSES/README.md`, `docs/CONTENT_PROVENANCE.md`, and
`docs/BRAND_ASSET_PROVENANCE.md`.

The academic Deck Library is separately licensed under CC BY 4.0. Its exact release
notice, attribution, review boundary, and integrity manifest are retained in
`library/`.

## Third party

KaTeX 0.18.4 is admitted under its MIT license with its license and provenance
README retained. Install-time dependencies retain their package licenses and
are not relicensed by Meshful.

## Excluded

Private source locators, capacity helpers, construction decks, predecessor
corpora, source PDFs, learner answers and history, provider outputs, launch
media, private-v1 runtime projections, and internal evidence are excluded.
